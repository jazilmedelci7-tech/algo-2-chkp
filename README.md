# Algorithmics Checkpoint

## Problem 1: Sum of Distinct Elements

This algorithm uses arrays and nested loops to calculate the sum of elements that appear in only one of the two arrays.

Example:

- Set 1: [3, 1, 7, 9]
- Set 2: [2, 4, 1, 9, 3]
- Output: 13

## Problem 2: Dot Product

The dot product is calculated using the formula:

ps = v1[1] * v2[1] + ... + v1[n] * v2[n]

### Procedure Version

The procedure calculates the dot product and returns the result through the `ps` parameter.

### Function Version

The function returns the dot product directly.

### Orthogonality

Two vectors are orthogonal if their dot product equals zero.
